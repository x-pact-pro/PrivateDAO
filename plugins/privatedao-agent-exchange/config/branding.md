# PrivateDAO Branding

## Brand identity

- Brand: **PrivateDAO**
- Product: **PrivateDAO Agent Exchange**
- Payment product: **PrivatePAY x402**
- Token symbol: **PDAO**
- Core promise: **Private decisions. Verifiable outcomes.**

## Approved commercial wording

“PrivateDAO helps organizations run sensitive work through controlled workflows and share only the evidence needed to trust the result.”

## Visual assets

- `assets/PrivateDAO_Full_Lockup_Transparent_Approx.png`: primary lockup.
- `assets/PrivateDAO_Symbol_Transparent_1024.png`: large symbol use.
- `assets/PrivateDAO_Symbol_Vector_Reconstructed.svg`: scalable symbol use.

Use the full lockup for product and investor materials. Use the symbol for compact plugin cards and tool lists. Keep sufficient whitespace and do not recolor, stretch, or combine it with token-market branding.

## Tone

Clear, calm, commercial, evidence-led, and easy for a non-technical buyer to understand. Avoid hype, guaranteed returns, “untraceable”, “risk-free”, and unsupported universal-chain claims.

# Skill: Verification Suite

Use the smallest verification path that answers the question:

- `verify.basic`: first-pass record or evidence check.
- `verify.deep`: deeper paid verification when the basic result is insufficient.
- `receipt.verify`: validate a completed receipt.
- `contract.inspect`: inspect program or contract structure.
- `transaction.simulate`: test a transaction before signing.
- `forensics.trace`: detailed Solana transaction tracing.

Return what was checked, what was not checked, the timestamp, network, confidence limits, and the receipt or evidence link.

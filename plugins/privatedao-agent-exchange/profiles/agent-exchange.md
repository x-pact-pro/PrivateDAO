# Agent Exchange Profile

PrivateDAO Agent Exchange is the machine-facing product surface.

It lets compatible AI agents discover services, understand accepted inputs, request work, handle quote-first payment, receive structured output, and verify receipts.

Current public endpoint: https://agents.privatedao.org/mcp

PrivatePAY x402 is one of the listed capabilities and uses explicit user approval for payment or signing. The Agent Exchange does not receive a user's private keys.

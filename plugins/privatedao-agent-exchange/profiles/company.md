# PrivateDAO Company Profile

**Name:** PrivateDAO

**Short description:** Private software and Web3 infrastructure for sensitive organizational work, controlled execution, and verifiable outcomes.

**Customer value:** Organizations can keep sensitive details inside a governed process while sharing only the evidence needed by reviewers, partners, customers, or auditors.

**Primary products:** Proof Workflows, Private Governance, Treasury Coordination, Agent Exchange, and PrivatePAY x402.

**Official website:** https://privatedao.org/

**Official repository:** https://github.com/X-PACT/PrivateDAO

**Location shown on the public site:** Warsaw, Poland.

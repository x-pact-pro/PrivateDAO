# PDAO Wallet Chrome Extension Beta

Manifest V3 companion extension for the production PDAO Wallet surfaces.

- Live SOL/BTC/ETH prices from CoinGecko.
- Solana Mainnet balance read for a public address.
- Live Agent Exchange catalog discovery.
- PrivatePAY x402 and wallet handoff for explicit approval.
- No remote JavaScript, no seed phrase input, and no transaction signing inside the extension.

Load the directory as an unpacked extension for review. Chrome Web Store distribution requires the owner's developer account and final store approval.

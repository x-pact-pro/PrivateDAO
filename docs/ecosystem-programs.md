## Disclosure boundary

Program participation is not a blanket endorsement, certification, grant
award, customer reference, or claim that every listed product is enabled in
production. Each integration must still have its own configuration, security
boundary, runtime status, and independent evidence.

The MongoDB relationship has a production technical evidence path in the Agent
Exchange: MongoDB Atlas is used for idempotent evidence-history persistence and
search, while DynamoDB remains the canonical store for jobs, payments, and
receipts. MongoDB does not hold wallet keys or payment credentials.

IBM, AMD, Intel, and GitHub are recorded as ecosystem program relationships and
technical validation partners. Their presence here does not expose credentials
or imply that a provider endpoint is configured in every environment.

## Public positioning

PrivateDAO is a software and Web3 infrastructure project. Organizations can
use its privacy and proof workflows without becoming crypto companies, while
Web3-native teams can add verifiable private operations to existing systems.

The next product milestone is PDAO Wallet: corporate accounts for the six core
PrivateDAO workflows, an autonomous AI wallet, and a B2B wallet, with a planned
quantum-resilience layer above the Kernel and wallet.
